How it actually works

Three steps. No middle-man reselling.

01

We scan drop calendars

Each label's own site and socials — restock windows, raffle links, waitlists — checked on a schedule, not guessed at.

02

You set a watch

Pick the cities or labels you care about. One alert per drop, sent when the window actually opens.

03

You buy direct

Every link routes to the label's own store. We never hold inventory and never mark up a price.

We're small. We're not pretending otherwise.

ORBIT is a two-person watchlist that grew into a habit for a few hundred people. We won't show you a fake "50,000+ sneakerheads" counter to feel bigger than we are — the six labels above are the actual list we track today.

If a label stops shipping internationally, or a restock link goes dead, we pull the card the same day — not "coming soon" forever.
