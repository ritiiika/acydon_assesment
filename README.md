# ORBIT — Y2K Fashion Universe

A futuristic Y2K-inspired sneaker and luxury fashion discovery homepage
built for the Acydon Technologies Frontend Challenge.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive 390px mobile layout
- 1440px desktop layout
- Product search
- Category filtering
- Interactive product cards
- Luxury fashion section
- Brand constellation
- Y2K / futuristic visual system
- Responsive animations and micro-interactions

## Run locally

Open `index.html` in a browser.

## Deployment

Deployed with Vercel.
